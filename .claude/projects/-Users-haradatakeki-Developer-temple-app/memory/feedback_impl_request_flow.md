---
name: 実装前に依頼文を作成するフロー
description: 実装に入る前に依頼文（仕様・要件・変更対象ファイル・UIイメージ）をまとめた文章を先に作成する。ユーザーが確認してから実装に進む。
type: feedback
---

実装作業の前に、まず依頼文（Markdown形式）を作成してユーザーに確認を求める。

**Why:** ユーザーが「こんな感じで依頼していきましょう」と確認。実装前に要件・対象ファイル・UI イメージをすり合わせることでやり直しを防ぐ。

**How to apply:**
- 新機能・変更の実装を頼まれたら、いきなりコードを書かず、まず依頼文を Markdown で提示する
- 依頼文には「背景・課題」「要件（フロー変更・画面要件）」「実装方針（案A/B の比較）」「変更対象ファイル一覧」「UI イメージ（テキスト図）」を含める
- ユーザーの承認（「これで実装して」「OK」など）を得てから実装に着手する
