## Phase 31d（仮）: 参拝記録を「記録」タブに統合

### 機能要件
「記録」タブ（現状は学びの日記のみ）に参拝記録も統合し、ユーザーが「自分の歩み」として一元的に振り返れる UX を実現する。

### 設計議論が必要な点

#### データモデル
- 参拝記録の現状（DB schema、保存場所）
- 「参拝」を JournalEntry の moodTag や category として統合できるか
- 別エンティティ（PilgrimageEntry など）として管理するか

#### UI 統合方法の選択肢
- 並列（タブ切り替え）
- 時系列で混合表示
- フィルタで切り替え

#### 入口
- ユーザーが「参拝を記録する」UI 入口がどこにあるか
- /app/temples/[id] の「参拝を記録する」ボタンとの連携

#### 「あなたのてらログ」（/app/my）との役割分担
- /app/my: 振り返り、統計、ハイライト
- /app/journal: 詳細な記録一覧
- 統合後の責任分担

### 着手タイミング
Phase 31a-fix-5 完了後
