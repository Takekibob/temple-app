# 設計書 03｜エラーページ（404・500・メンテナンス）

## 背景・課題

- 現在 404/500 時は Next.js のデフォルト白画面が表示される
- ブランドイメージを損ない、ユーザーが迷子になる
- `planStatus = CANCELLED` 時の画面もない

---

## 要件

| ページ | 表示タイミング |
|---|---|
| 404 Not Found | 存在しないURLにアクセス |
| 500 / Error | サーバーエラー・未処理例外 |
| メンテナンス | `planStatus = CANCELLED/SUSPENDED` の檀家アクセス時 |

---

## 実装方針

### ファイル構成

```
src/app/
├── not-found.tsx          ← 404 (App Router の規約ファイル)
├── error.tsx              ← 500 / クライアントエラー境界
├── global-error.tsx       ← ルートレイアウトのエラー境界
└── maintenance/
    └── page.tsx           ← planStatus=CANCELLED 時の檀家向け画面
```

### デザイン方針
- てらログのブランドカラー（amber）を使用
- お寺らしいアイコン（🏯）を使用
- ログイン画面・一般画面どちらの背景にも馴染む `bg-stone-50`
- ボタン：トップへ戻る / ログアウト（状況による）

---
