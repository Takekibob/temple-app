# 設計書 01｜法律文書ページ（プライバシーポリシー・利用規約・特定商取引法）

## 背景・課題

- 個人情報（氏名・住所・命日・電話番号等）を扱うため **個人情報保護法** 上の表記が必須
- 有料サービスとして販売する場合 **特定商取引法** の表記が法的義務
- **利用規約** がないと契約関係・免責が曖昧になり営業時に信頼を損なう

---

## 要件

### ページ一覧

| URL | 内容 | 対象 |
|---|---|---|
| `/privacy` | プライバシーポリシー | 全ユーザー |
| `/terms` | 利用規約 | 全ユーザー |
| `/tokushoho` | 特定商取引法に基づく表記 | 有料契約するお寺 |

### 共通要件
- 認証不要（未ログインでもアクセス可能）
- ログイン画面・登録画面・フッターからリンクを貼る
- 印刷・PDF 保存を想定したシンプルなレイアウト

---

## 各ページの内容要件

### `/privacy`　プライバシーポリシー

```
1. 事業者情報
2. 取得する個人情報の種類
   - 氏名・住所・電話番号・メールアドレス
   - 故人情報（戒名・命日・享年）
   - 決済情報（Stripe 経由・本アプリでは保持しない）
3. 利用目的
   - 寺院管理業務の提供
   - メール・プッシュ通知の送信
   - サービス改善のための統計分析
4. 第三者提供の原則禁止と例外
5. 委託先（Supabase / Vercel / Stripe）
6. 保存期間
7. 開示・訂正・削除の請求方法
8. Cookie・アクセス解析
9. お問い合わせ窓口
10. 改定
```

### `/terms`　利用規約

```
1. 定義（サービス・ユーザー・寺院アカウント）
2. 利用登録・アカウント管理
3. 料金・支払い（プラン・トライアル・自動更新）
4. 禁止事項
5. 知的財産権
6. 免責事項（データ損失・サービス停止）
7. サービスの変更・停止・終了
8. 解約（即時解約可・返金ポリシー）
9. 準拠法・管轄裁判所（東京地方裁判所）
10. 改定
```

### `/tokushoho`　特定商取引法

```
販売業者名：[会社名]
代表者：[代表者名]
所在地：[住所]
電話番号：[電話番号]（メール優先）
メールアドレス：[メールアドレス]
販売価格：各プランページ参照
支払方法：クレジットカード（Stripe）
支払時期：月次自動課金
サービス提供：契約後即時
返品・返金：サービスの性質上、原則不可
　　　　　　（初月トライアル期間中の解約は課金なし）
```

## 実装方針

### ファイル構成

```
src/app/
├── (public)/               ← 認証不要のレイアウトグループ（新規作成）
│   ├── layout.tsx          ← シンプルなヘッダー（ロゴ + ログインリンク）
│   ├── privacy/
│   │   └── page.tsx
│   ├── terms/
│   │   └── page.tsx
│   └── tokushoho/
│       └── page.tsx
```

### レイアウト方針
- ログインページと同じ `/auth/layout.tsx` の背景を流用
- 白背景・最大幅 `max-w-3xl`・十分なパディング
- 見出し `h2`・本文 `text-sm text-stone-700`・セクション間に区切り線

### リンク追加箇所

| 場所 | リンク |
|---|---|
| `src/app/auth/login/LoginForm.tsx` | フッターに「利用規約」「プライバシーポリシー」 |
| `src/app/auth/register/page.tsx` | 「登録することで利用規約・プライバシーポリシーに同意したものとみなします」 |
| `src/app/(admin)/admin/` | サイドバーフッターに「利用規約」「プライバシーポリシー」 |
